# Code of Conduct

## Our pledge

We want participation in Omega Cognitive Kernel to be respectful, constructive, and safe. Contributors should be able to discuss implementation, research assumptions, safety boundaries, and product trade-offs without harassment or discrimination.

## Expected behavior

Examples of behavior that contributes to a positive environment include:

- Using welcoming and inclusive language.
- Respecting different viewpoints, experiences, and technical backgrounds.
- Giving and receiving constructive feedback.
- Focusing criticism on ideas, code, documentation, or behavior rather than people.
- Taking responsibility for mistakes and helping repair their impact.
- Respecting the project's security and responsible-disclosure process.

## Unacceptable behavior

The following behavior is not acceptable:

- Harassment, discrimination, threats, intimidation, or personal attacks.
- Sexualized language or unwanted sexual attention.
- Trolling, deliberate disruption, doxxing, or publishing private information without consent.
- Unwelcome commercial solicitation or repeated off-topic promotion.
- Knowingly submitting malicious code, credentials, private data, or a deliberately unsafe proof of concept.
- Publicly disclosing an unpatched security vulnerability outside the process in [`SECURITY.md`](SECURITY.md).

## Scope and enforcement

This Code of Conduct applies in project repositories, issues, pull requests, discussions, reviews, release coordination, and project-related communication. Maintainers may remove or edit content, close discussions, request corrective action, or restrict participation when behavior violates this policy.

To report a conduct concern, contact the repository maintainers privately through the GitHub account that owns the repository. Do not use public issues for sensitive reports. Security vulnerabilities must follow [`SECURITY.md`](SECURITY.md).

Reports should include enough context to investigate, but should not include unnecessary personal information or secrets. Maintainers will handle reports as confidentially as practical and will avoid conflicts of interest when deciding how to respond.
